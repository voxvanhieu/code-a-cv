Code a CV helps you manage your CV(s) as Code: version-controlled, tailored per job requirement, and consistently formatted.

Usage: cac <COMMAND>

Commands:
  init     Create a starter CV or import JSON Resume data
  build    Validate and render a CV as PDF or HTML
  check    Check CV content
  convert  Convert a CV to another source format
  themes   List and manage themes
  help     Print this message or the help of the given subcommand(s)

Options:
  -v, --version  Print version
  -h, --help     Print help

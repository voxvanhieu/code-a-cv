List and manage themes

Usage: cac themes <COMMAND>

Commands:
  list     List embedded and installed themes
  install  Install an embedded theme
  remove   Remove an installed theme
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

Examples:
  cac themes list
  cac themes install classic --local
  cac themes remove classic --local

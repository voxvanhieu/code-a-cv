Find, install, and manage themes

Usage: cac themes <COMMAND>

Commands:
  list     List embedded and installed themes
  search   Search downloadable themes
  info     Show a downloadable theme's metadata
  install  Install a downloadable theme
  remove   Remove an installed theme
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

Examples:
  cac themes list
  cac themes search blue
  cac themes info classic-blue
  cac themes install classic-blue --local
  cac themes remove classic-blue --local

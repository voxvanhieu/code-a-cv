# shapes

A sidebar layout with soft geometric shapes behind the skills column, a
muted accent palette, and numbered main-column headings. Original design
in the sidebar genre.

Select it with `"theme": "shapes"`. The sidebar column carries Skills,
Languages, and References; everything else renders in the main column
with 01/02 numbering. Photo: add `Photo: your.jpg` to the CV header and
the file next to `settings.json`.
